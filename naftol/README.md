Les imatges STM són a partir d'una molècula de naftol optimitzada. El naftol es una molec. amb gran importancia en l'ambit químic utilitzada tant en la industria 
farmacèutica i cosmètica, com per a la fabricació de colorants.

Les imatges obtingudes amb sigut amb el VMD amb voltages de 5V (imagte 5V), amb -5V (imatge m5V) i finalment un valor de 3V (imatge 3V). 
Hem utilitzat tres voltatges diferents per poder veure bé les diferentes densitats electroniques.
